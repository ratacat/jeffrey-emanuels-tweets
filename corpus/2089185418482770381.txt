I decided to add a super-realistic, physics-based, parameterized Wright Flyer simulation to https://t.co/NlHMSlOgV2 that can be used in a web browser with wasm and ThreeJS in real-time. 

Why? I don't know, I feel a compulsion to do things and I've been reading a lot about the ol' Wright Bros today and so was inspired. I also think it will be another great way to put FrankenSim through its paces in a fun, visible way.

Anyway, as part of that work, I invoked my /planning-workflow skill, which first creates a markdown plan document in the local harness (Claude Code with Fable in this case), but then instructs you to show it to GPT Pro in the web app for multiple rounds so it can improve the plan.
